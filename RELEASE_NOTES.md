# v1.0.0

First version accompanying the preprint "Laya-MLX as a Fast Local Decision Engine for Browser Automation".

- Paper (PDF), LaTeX source bundle for arXiv, and a self-contained replication package are attached as release assets.
- Raw per-decision results for every experiment are in `experiments/results/`.
- Known limitations are listed in the paper (small samples, one machine, Laya-ML-only end-to-end runs).
